## Результат работы predictions.py:

#### Прогноз вычисления:
 * **1)** 2 + 3 * 4 == 14
 *  **2)** (2 + 3) * 4 == 20
 * **3)** 17 // 5 == 3.4
 * **4)** 17 % 5 == 2
 * **5)** -7 // 2 == -3.5

#### Результат на Python:
  
 * **1)** 2 + 3 * 4 == 14
 * **2)** (2 + 3) * 4 == 20
 * **3)** 17 // 5 == 3
 * **4)** 17 % 5 == 2
 * **5)** -7 // 2 == -4

### Объяснения: 
 * Первое и второе вычисление сошлись т.к. Python следует математическим правилам порядка операций(операция * выше по приоритету чем + или -)
 * Во втором скобки дают выше приоритет чем *
 * В третьем и в пятом // это целоцисленное деление и оно округляет в меньшую сторону т.е. 3.4 -> 3 и -3.5 -> -4
 * В четвертом % это остаток от деления и он одинаков
